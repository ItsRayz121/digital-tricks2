Export & Deploy
How the admin panel works:
Changes you save here are stored in your browser's localStorage and applied live on the main site when opened on the same browser. To make changes permanent on your live site (GitHub + Vercel), click Export config.js, replace the file in your GitHub repo, and Vercel will auto-redeploy.
Export Preview
Click "Export config.js" above to preview.
Deployment Steps
1. Make changes in Admin Panel → Save Changes
2. Click "Export config.js" — file downloads automatically
3. Open your GitHub repo (github.com/YOUR-USERNAME/digital-tricks)
4. Click on site-config.js → Edit (pencil icon)
5. Replace all content with the downloaded file contents
6. Click "Commit changes"
7. Vercel detects the push and redeploys in ~30 seconds
8. Visit your live site to confirm the update
